# Algorithms4Robotics
A collection of path planning algorithm simulations.

The aim of this project is to demonstrate the operation of traditional algorithms used in robotics, with a strong focus on visual simulation and clear algorithmic descriptions.

## Algorithms
- [Bug Algorithms](bugs/README.md)
  - Bug 1
  - Bug 2
  - Tangent Bug
- [Grid-based navigation](gridnav/README.md)
  - Wavefront
  - A*
